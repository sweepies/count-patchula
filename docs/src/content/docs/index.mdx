## What it does

Point the Count at some repositories with a token and a small Pkl file. He reads
their manifests through the GitHub API, looks up newer versions, and opens one
pull request per update, each with a regenerated lockfile, release notes and a
verified commit signed by GitHub.

```sh
patchula run --dry-run acme/my-app   # look first
patchula run acme/my-app             # then for real
```

```pkl
// patchula.pkl
amends "PatchulaConfig.pkl"

rules {
  new Rule {
    select { updates { "patch" } }
    apply { merge = true }
  }
}
```

Over 30 ecosystems are supported, from npm and Cargo to Helm, Terraform and Nix
flakes. See the [compatibility matrix](/renovate/compatibility/).
