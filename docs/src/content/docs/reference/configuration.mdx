This is the complete repository schema, `PatchulaConfig.pkl`, bundled with every
build. Print it with `patchula config schema`. The [configuration guide](/guide/configuration/)
explains how the pieces fit together.

## Top-level fields

| Field | Type | Default |
|---|---|---|
| `managers` | `Listing<Manager>` | every manager |
| `defaults` | `Policy` | see the schema |
| `rules` | `Listing<Rule>` | two built-in rules: [reference data](/guide/configuration/#reference-data) fast-tracked, and `preserve` for Cargo, pyproject, Bundler and Composer |
| `files` | `Listing<FileSet>` | each manager's own patterns |
| `extractors` | `Listing<Extractor>` | none |
| `ignore` | `Listing<String>` | none |
| `exclude` | `Listing<String>` | `**/node_modules/**`, `**/bower_components/**`, `**/vendor/**`, `**/.git/**`, `**/test/**`, `**/tests/**`, `**/__tests__/**`, `**/__fixtures__/**`, `**/fixtures/**`, `**/examples/**` |
| `prs` | `PullRequests` | see the schema |
| `lockfiles` | `Lockfiles` | see the schema |
| `security` | `Security` | see the schema |
| `warnings` | `Warnings` | see the schema |
| `gitlab` | `Gitlab` | see the schema |
| `useVersionsHost` | `Boolean` | `true` |
| `submodules` | `Boolean` | `false`; accepted, not acted on yet |
| `ignoreAuthors` | `Listing<String>` | none; accepted, not acted on yet |
