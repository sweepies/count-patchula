==> patchula apply --help
Write available updates into the current working tree, without branches or pull
requests.

Exit codes: 0 = nothing selected is left to apply; 1 = runtime error; 2 = usage
or configuration error; 3 = selected updates are still waiting (`--check` or
`--dry-run` found some, or some could not be written in place); 4 = a
dependency's lookup failed, so its updates are unknown. 4 takes precedence over
3.

Usage: patchula apply [FLAGS]

Flags:
      --cache <DIR>           Cache directory, shared across checkouts (default:
                              `patchula` in the user cache directory:
                              `~/Library/Caches` on macOS, else `XDG_CACHE_HOME`
                              or `~/.cache`).
      --settings <FILE>       Operator settings file; also PATCHULA_SETTINGS
                              (default: `patchula/settings.pkl` in
                              `XDG_CONFIG_HOME` or `~/.config`, when present).
      --concurrency <N>       Maximum concurrency (1–100), overriding the
                              settings file; HTTP limits are per host (default:
                              8).
      --config <FILE>         Local Pkl config file to use instead of the
                              working tree's `patchula.pkl`.
      --default-config        Use default configuration when the working tree
                              has no `patchula.pkl`, instead of prompting.
                              Conflicts with `--config`.
      --manager <MANAGER>     Only updates from this manager; repeat for more.
                              [possible values: npm, bun, github-actions, mise,
                              cargo, dockerfile, compose, go, terraform,
                              kubernetes, kustomize, flux, helm-values,
                              pyproject, pre-commit, helm, devcontainer,
                              woodpecker, copier, maven, gradle, nuget, bundler,
                              composer, gitlabci, gitlabci-include, nix, apm,
                              pkl, regex]
      --dependency <PATTERN>  Only dependencies matching this name or package,
                              with config's `glob:`, `regex:` and `!`; repeat
                              for more.
      --type <TYPE>           Only updates of this type; repeat for more.
                              [possible values: major, minor, patch, pin,
                              digest]
      --dry-run               Print the unified diff of what would be written,
                              and write nothing.
      --check                 Write nothing; exit 3 if any selected update is
                              waiting, or 4 if a lookup failed.
      --copier                Also run `copier update` for each selected
                              template before other updates. Template code runs
                              locally as you; the tree must be clean and
                              `--trust` is never passed.
      --copier-defaults       With `--copier`, take default answers for copier
                              prompts, for use without a terminal.
  -h, --help                  Print help

Global flags:
  -v, --verbose               Show cache details, request counts, and phase
                              timings; repeat for debug logs.
      --color <WHEN>          Control ANSI color in output.
                              [possible values: auto, always, never]
                              (default: auto)
      --json                  Emit command results and errors as JSON; configs
                              stay Pkl.

Examples:
    Write every available update
    $ patchula apply

    Write nothing; exit 3 if updates are waiting
    $ patchula apply --check

    Show patch updates as a unified diff
    $ patchula apply --dry-run --type patch

    Write only actions/* updates
    $ patchula apply --manager github-actions --dependency 'glob:actions/*'

==> patchula run --help
Create or update dependency branches and pull requests on GitHub with verified
API commits.

Reads GitHub rather than the working tree, even with `--dry-run`. With no
repository, runs this checkout's GitHub repository; `--dir` with `--dry-run`
plans from a local directory instead.

Failed lookups are reported but the run still exits 0, since it keeps the pull
requests it could plan; it holds off auto-merge and closing pull requests for
that repository.

Usage: patchula run [FLAGS] [OWNER/REPO]…

Arguments:
  [OWNER/REPO]…  Repositories as owner/repo, read through the GitHub API; omit
                 for this checkout's GitHub repository.

Flags:
      --all-repos         Scan every repository the token can reach.
      --cache <DIR>       Cache directory, shared across checkouts (default:
                          `patchula` in the user cache directory:
                          `~/Library/Caches` on macOS, else `XDG_CACHE_HOME` or
                          `~/.cache`).
      --settings <FILE>   Operator settings file; also PATCHULA_SETTINGS
                          (default: `patchula/settings.pkl` in `XDG_CONFIG_HOME`
                          or `~/.config`, when present).
      --concurrency <N>   Maximum concurrent repository scans (1–100),
                          overriding the settings file; HTTP limits are per host
                          (default: 8).
      --config <FILE>     Local Pkl config override applied to every selected
                          repository.
      --config-dir <DIR>  Per-repository overrides: `DIR/<owner>/<name>.pkl`,
                          then `DIR/<name>.pkl`; other repositories use their
                          own `patchula.pkl`, or are skipped without one.
                          Conflicts with `--config`.
      --dir <DIR>         Plan branches and diffs from a local directory instead
                          of GitHub; requires `--dry-run`.
      --recheck <WHEN>    When a ticked PR or dashboard checkbox takes effect;
                          also PATCHULA_RECHECK (default: next-run).
                          [possible values: now, next-run]
      --dry-run           Print planned branches, files and unified diffs
                          without writing to GitHub.
  -h, --help              Print help

Global flags:
  -v, --verbose           Show cache details, request counts, and phase timings;
                          repeat for debug logs.
      --color <WHEN>      Control ANSI color in output.
                          [possible values: auto, always, never]
                          (default: auto)
      --json              Emit command results and errors as JSON; configs stay
                          Pkl.

Examples:
    Plan branches and diffs for acme/app, writing nothing
    $ patchula run --dry-run acme/app

    Open or update pull requests for acme/app
    $ patchula run acme/app

    Run every repository the token can reach
    $ patchula run --all-repos --config-dir overrides
