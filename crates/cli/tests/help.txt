==> patchula apply --help
Write available updates into the working tree here, without branches or pull
requests.

Exit codes: 0 = nothing selected is left to apply; 1 = runtime error; 2 = usage
or configuration error; 3 = selected updates are still waiting: `--check` or
`--dry-run` found some, or some could not be written in place.

Usage: patchula apply [FLAGS]

Flags:
      --cache <DIR>               Cache directory, shared by every checkout.
                                  Default: `patchula` in the user cache
                                  directory (`~/Library/Caches` on macOS, else
                                  `XDG_CACHE_HOME` or `~/.cache`).
      --concurrency <N>           Maximum concurrent repository scans (1–100);
                                  HTTP limits are per host.
                                  (default: 8)
      --host-concurrency <HOST=LIMIT>  Override a host's HTTP limit (1–100);
                                  repeat per host. Default: 16.
      --registry-freshness-secs <SECS>  Freshness seconds for OCI tag lists
                                  without validators; 0 uses upstream
                                  policy.
                                  (default: 3600)
      --go-freshness-secs <SECS>  Minimum freshness seconds for Go proxy
                                  lists/latest; 0 uses upstream policy.
                                  (default: 3600)
      --config <FILE>             Local Pkl override applied to every selected
                                  repository.
      --default-config            Use the Count's defaults when the working tree
                                  has no `patchula.pkl`, instead of asking.
                                  Conflicts with `--config` and `--config-dir`.
      --manager <MANAGER>         Only updates from this manager, such as
                                  github-actions; repeat for more.
      --dependency <PATTERN>      Only dependencies matching this name or
                                  package, with config's `glob:`, `regex:` and
                                  `!`; repeat for more.
      --type <TYPE>               Only updates of this type; repeat for more.
                                  [possible values: major, minor, patch, pin,
                                  digest]
      --dry-run                   Print the unified diff of what would be
                                  written, and write nothing.
      --check                     Write nothing; exit 3 if any selected update
                                  is waiting, or 4 if a lookup failed.
      --copier                    Also run your own `copier update` for each
                                  selected template, before the other updates.

                                  The template's code runs on this machine as
                                  you. The tree must be clean, the Count never
                                  passes `--trust`, and copier asks its
                                  questions on the terminal.
      --copier-defaults           With `--copier`, take the defaults for
                                  questions copier would ask, for use without a
                                  terminal.
  -h, --help                      Print help

Global flags:
      --recheck <WHEN>            When a ticked checkbox says it takes effect;
                                  also PATCHULA_RECHECK. Default: now in the
                                  server, next-run in the CLI.
                                  [possible values: now, next-run]
  -v, --verbose                   Show request counts and phase timings after a
                                  batch; repeat for debug logs.
      --color <WHEN>              Control ANSI colors in diagnostics.
                                  [possible values: auto, always, never]
                                  (default: auto)
      --json                      Emit command results and errors as JSON;
                                  configs stay Pkl.

Examples:
    Write every available update here
    $ patchula apply

    Write nothing; exit 3 if updates are waiting
    $ patchula apply --check

    Show the patch updates as a diff
    $ patchula apply --dry-run --type patch

    Write only the actions/* updates
    $ patchula apply --manager github-actions --dependency 'glob:actions/*'

                                  [possible values: auto, always, never]
                                  (default: auto)
      --json                      Emit command results and errors as JSON;
                                  configs stay Pkl.

    $ patchula tui

    Browse a repository through the API

    Print a plain snapshot, for pipes and CI logs
    $ patchula tui --once
